# I+D HUB

Repositorio y plataforma de estudio para la asignatura **Investigación y Desarrollo de Nuevos Productos**.

El contenido base fue desglosado a partir del sílabo adjunto por el usuario. El documento fuente se trató únicamente como material académico de referencia; sus textos administrativos no fueron asumidos como instrucciones de trabajo.

## Estructura actual

- `platform/index.html`: inicio con acceso a los capítulos.
- `platform/pages/`: páginas separadas por capítulo.
- `content/chapters.js`: datos estructurados con subtemas según la numeración del sílabo.
- `docs/`: versión documental de cada capítulo.
- `assets/`: recursos visuales del sitio.

## Capítulos

1. Fundamentos de la Investigación y Desarrollo
2. Planeación y front end del desarrollo de nuevos productos/servicios
3. Proceso de desarrollo de nuevos productos y/o servicios
4. Prototipado

## Uso

Abre `platform/index.html` en el navegador. La plataforma funciona sin servidor.

## Resultados de aprendizaje integrados

- Identificar oportunidades de innovación y requerimientos de diseño.
- Analizar problemas con herramientas cualitativas y datos.
- Formular soluciones considerando restricciones técnicas, económicas y de contexto.
- Evaluar conceptos, prototipos y alternativas para nuevos productos o servicios.
- Usar herramientas de soporte como Excel, QFD, Kano, prototipado y validación.
